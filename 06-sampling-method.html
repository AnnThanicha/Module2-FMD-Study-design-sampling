6. Sampling method

The target population is the group you want to make conclusions about. The sampling method is how you select units from it.

6.1 Six sampling methods

MethodHow it worksMain considerationWhen to use
Simple randomRandomly select units from the full listRequires a suitable listSmall, well-listed populations
SystematicRandom start, then every k-th unitAvoid patterns related to diseaseAnimals in a milking line, records in order
StratifiedSample separately within defined groupsAccount for selection fractionsGroups differ (herd size, district)
ClusterSelect groups, assess all or many units within themWithin-group similarityNo animal list, but a farm list exists
MultistageSample groups, then units within groupsAccount for both stagesLarge regional surveys
ConvenienceSelect easily available unitsLimited representativenessPilot studies only
