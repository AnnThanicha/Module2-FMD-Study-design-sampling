Tips for using online calculators
  • OpenEpi reports three methods side by side for cohort and case-control designs: Kelsey, Fleiss and Fleiss with continuity correction. Read the row that matches the method you used.
  • Calculators may differ from hand calculation by 1–2 animals because of rounding of Z values, and some tools use other methods (e.g. Epitools for cohort and case-control). State the tool and method in your report.
  • OpenEpi enters percentages (e.g. 20) rather than proportions (0.20). Check the input format of each tool.
  • Apply the adjustments in Sections 7.2–7.5 (design effect, finite population correction, expected losses) after the basic calculation. The OpenEpi Proportion module can include the design effect and population size directly.

7.2 Clustering and the design effect

Animals in the same herd, pen or village share feed, housing and pathogens, so each extra animal from the same herd adds less information.

DEFF = 1 + (m − 1) ρ    ncluster = n₀ × DEFF    clusters = ncluster / m
SymbolMeaning
mAverage number of animals sampled per cluster (e.g. per farm)
ρ (rho)Intracluster correlation: how similar animals in the same cluster are (0 = not alike, 1 = identical)
n₀Sample size for simple random sampling

Infectious diseases often have ρ of 0.1–0.3 or more.
Production traits such as milk yield often have ρ of about 0.05–0.2.
Take ρ from similar published studies or pilot data.

Worked example: n₀ = 246, m = 20, ρ = 0.10 gives DEFF 2.9, 714 cows, 36 farms (720 cows). With m = 10: 468 cows, 47 farms. Try both above; fewer cows per farm needs fewer animals but more farm visits, so balance with cost.

7.3 Finite population correction

If the sample is a large share of a small population, you need fewer animals. Apply when n₀ is more than about 5–10% of N. For cluster sampling, apply it to the number of farms.

nf = n₀ / [ 1 + (n₀ − 1) / N ]

Worked example: 450 dairy farms, p = 0.20, ±5%, 95%: n₀ = 246 → nf = 160 (86 fewer farms). With N = 10,000 the saving is only 5, so ignore it.

7.4 Missing data and loss to follow-up

nadj = n / (1 − L)

Worked example: you need 246 usable samples and expect 15% loss. Correct: 246 / 0.85 = 289.4, round up to 290 (290 × 0.85 = 246.5 usable). Adding 15% instead gives 283, of which only 240.6 are usable, about 6 short.
Estimate L from pilot data, earlier studies or the laboratory failure rate. Loss related to the outcome (e.g. the sickest calves die before sampling) biases the result; more animals do not fix that.

7.5 Putting the adjustments together

  1. Calculate basic n₀ (7.1).
  2. Multiply by DEFF if sampling clusters (7.2).
  3. Apply the FPC if the sample is a large share of N (7.3).
  4. Divide by (1 − L) for expected loss (7.4).
  5. Round up at the end, not at each step.

These are introductory approximations; unequal cluster sizes need a more detailed method.
