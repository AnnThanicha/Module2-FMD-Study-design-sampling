# Module 2 – Planning Epidemiological Studies, Sampling & Sample Size

Static website (no build step). One HTML page per section, shared `style.css` and `app.js`.

## Publish on GitHub Pages
1. Create a repository and upload **all files in this folder** to the repository root (keep them together).
2. Settings → Pages → Source: *Deploy from a branch* → branch `main`, folder `/ (root)` → Save.
3. After a minute the site is at `https://<user>.github.io/<repo>/` (opens `index.html`).

Files: `index.html` (overview), `01-…` to `09-…` (sections), `10-further-reading.html`, images (`fig_*`, `photo_cows.jpg`), `Dairy_sim.xlsx` (exercise data).
